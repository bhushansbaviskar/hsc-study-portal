# HSC Board Prep

Mobile-first board-exam prep portal for Maharashtra HSC Std 12 Science (English medium, Balbharati).
Live: https://bhushansbaviskar.github.io/hsc-study-portal/

- Plain HTML/CSS/JS, no build step, no dependencies.
- Content lives in `content/` (one JSON file per chapter). Add a chapter by adding a file and listing it in `content/catalog.json`.
- No textbook PDFs, past papers or student data are stored in this repo. Textbook links point to private files in the owner's Google Drive.
